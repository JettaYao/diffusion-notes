一步只能得到平均，
多步才能得到样本

扩散和 flow matching 的网络，每一步学到的都是"条件均值"。只用一次，得到的是所有训练数据的平均；接力用几十次，得到的是一个具体的样本。上篇把这里用到的概率论一个个讲清楚，下篇用它们解释这件事。全篇只用一个例子：训练数据只有 +1 和 −1 两个点。

1概率分布

概率分布回答"每种可能各占多少"，所有可能加起来正好是 100%。

随机变量是结果还没确定的量。"从训练集里随手抽一条数据"，抽出来是什么事先不知道，它就是一个随机变量。本例的训练集只有两条数据：+1 和 −1。随手抽一条，记作 x₀，抽到 +1 和 −1 的可能各占 50%。这就是 x₀ 的概率分布。

分布有两类：

  • 离散：可能的结果能一个个数出来，每个结果直接对应一个概率。x₀ 就是这种。大模型预测下一个 token 也是这种，叫类别分布。
  • 连续：结果可以是任意实数，比如噪声 ε。这时恰好等于某个值的概率是 0，只能问"落在某个区间里的概率"，它等于概率密度曲线在这个区间下面的面积。密度是"单位长度上的概率"，所以它可以大于 1，只要曲线下的总面积是 1。

描述一个分布最常用的两个数：

  • 期望（均值）：每个可能的值乘以它的概率，再加起来。x₀ 的期望是 0.5 × (+1) + 0.5 × (−1) = 0。
  • 方差：每个值离均值有多远，取平方后按概率平均；方差开根号叫标准差。x₀ 的方差是 1。

高斯分布（也叫正态分布）记作 N(μ, σ²)：一条钟形曲线，μ 是中心，σ 是宽度，也就是标准差。注意括号里第二个位置写的是方差 σ²。噪声 ε 服从 N(0, 1)。

先记住一件事：x₀ 的分布有两个峰（+1 和 −1），它的均值 0 却落在两峰之间，是一个根本不会出现的值。这就是多峰分布的均值的问题，也是全页的核心。

2联合、条件、边缘

条件分布就是"只看满足某个条件的那部分情况，再把它们重新凑成 100%"。

加噪的规则是我们自己定的，不需要学：

xt = (1 − t) · x₀ + t · ε， ε ~ N(0, 1)，ε 和 x₀ 独立

t = 0 时，xt 就是 x₀；t = 1 时，xt 就是纯噪声 ε；中间是两者按比例混合。

同时考虑 x₀ 和 xt 两个量，会用到三种分布：

  • 联合分布 p(x₀, xt)：两个量同时取某一组值的可能。
  • 条件分布 p(xt | x₀)：已知 x₀ 时 xt 的分布。已知 x₀ = +1 时，xt = (1 − t) + t·ε，也就是 N(1 − t, t²)：以 1 − t 为中心、宽度为 t 的钟形。x₀ = −1 时是以 −(1 − t) 为中心的同样形状。
  • 边缘分布 p(xt)：不管 x₀ 是多少，xt 本身的分布。做法是把两种情况按各自的概率加起来：½·N(1 − t, t²) + ½·N(−(1 − t), t²)。t 小时它是两个分开的峰；t 越大，两个峰越宽、越靠近，最后合成一个。

下篇要反复用到两个事实：

  • t = 1 时，xt = ε，和 x₀ 完全独立。看到 x₁，对 x₀ 一点信息都没有。
  • 链式法则：p(a, b) = p(a) × p(b | a)。量多时就一路乘下去。它是精确的，不需要任何假设。大模型给一整段文本算概率，就是这样一个 token 一个 token 乘出来的。

3贝叶斯公式：先验、似然、后验、证据

贝叶斯公式把"由因推果"的概率，翻成"由果推因"的概率：后验 = 似然 × 先验 ÷ 证据。

已知 x₀ 求 xt 的分布很容易，规则是我们定的。但去噪要回答的是反方向的问题：看到了 xt，x₀ 是 +1 还是 −1？

贝叶斯公式就是做这个翻转的。它的来历只有一行："x₀ 和 xt 同时出现"的可能，可以按两种顺序算，结果必然相等：

p(x₀) × p(xt | x₀) = p(xt) × p(x₀ | xt)

两边同除以 p(xt)：

p(x₀ | xt) = p(xt | x₀) × p(x₀) ÷ p(xt)

这四项各有名字。名字描述的是角色：谁是不知道、要推断的，谁是已经看到的。这里不知道的是 x₀，看到的是 xt。

名字写法本例里是什么一句话
先验p(x₀)+1、−1 各 50%，也就是数据分布本身看到 xt 之前，对 x₀ 的判断
似然p(xt | x₀)，固定看到的 xt加噪规则：假如 x₀ 是 +1（或 −1），加噪后恰好得到眼前这个 xt 的可能每个候选答案对眼前数据的解释力
证据p(xt)上一节的边缘分布不管 x₀ 是什么，看到这个 xt 本身有多常见；它是分母，把后验凑成 100%
后验p(x₀ | xt)看到 xt 之后，x₀ 是 +1 和 −1 的可能各是多少看到数据之后的判断

概率和似然：同一个式子，两种读法

p(xt | x₀) 这同一个式子：

  • 固定 x₀，看 xt 取各个值：这是一个概率分布，曲线下的面积是 1。
  • 固定已经看到的 xt，看 x₀ 取各个值：这是似然，它给每个候选答案打分。几个分数加起来一般不是 1，只有相对大小有意义。

下图里，蓝线是 x₀ = +1 时 xt 的分布，玫红线是 x₀ = −1 时的，黑线是两者的平均，也就是证据 p(xt)。拖动 xt：竖线和蓝线、玫红线交点的高度，就是两个似然。

横着看是概率：一条曲线，面积是 1。竖着看是似然：一根竖线上的几个高度，加起来不是 1。

在这个例子里，后验能精确写出来。两个似然之比是 e2(1−t)xt/t²，先验各半，于是 P(x₀ = +1 | xt) = 1 / (1 + e−2(1−t)xt/t²)。把 t 调小，可以看到同一个 xt 让后验变得更"有把握"，下篇会用到这一点。把 t 调到 0.2 以下，还能看到密度超过 1。

四个名字描述的是角色，不是固定贴在某个字母上的标签。换一个问题，比如第 6 节的"训练时猜权重"，未知的东西换了，四个角色就换成了另一批东西。

4条件期望：后验的平均

后验均值是"把每个可能的答案按后验概率加权平均"。用 MSE 训练的网络，学到的正是它。

条件期望 E[x₀ | xt] 是"已知 xt 时，x₀ 的期望"，也叫后验均值。本例中：

E[x₀ | xt] = P(+1 | xt) · (+1) + P(−1 | xt) · (−1) = tanh( (1 − t) · xt / t² )

tanh 是一条从 −1 平滑过渡到 +1 的 S 形曲线。

为什么 MSE 会学到它。同一个输入 xt，有时对应 +1，有时对应 −1，网络对这个输入却只能给出一个数。要让平方误差平均起来最小，这个数只能取这些可能答案的均值。原因是一个恒等式：

平均平方误差 = (猜测 − 均值)² + 方差

方差和猜测无关，所以猜均值时误差最小。

后验均值好不好用，完全取决于后验长什么样：

  • 后验很集中，比如几乎肯定是 +1：均值 ≈ +1，就是那个答案本身。
  • 后验分成两个峰，比如 +1、−1 各一半：均值是 0，落在两峰之间，是一个不存在的答案。

下篇的全部内容，就是在讲这两种情况分别在什么时候出现。

5模型：分布族与两种参数

模型是一个分布族：架构定下分布的形式，权重从族里选出一个成员。有输入时，权重不是分布参数，而是"从输入算出分布参数的规则"。

分布族是一类形式相同、只差几个数的分布。这几个数取不同的值，就得到族里不同的成员。比如所有高斯分布组成一个族，N(0, 1) 和 N(70, 100) 是其中两个成员。

"参数"这个词有两种意思，必须分开（模型参数与分布参数）：

无条件高斯 N(μ, σ²)条件高斯（回归网络）大模型扩散的去噪网络
训练时调的：模型参数μ、σ权重 θ权重 θ权重 θ
决定具体分布的：分布参数还是 μ、σ均值 μ = 网络(x)，每个输入各算一个logits = 网络(前文)，每个前文各算一组猜测 Dθ(xt, t)，每个 (xt, t) 各算一个
得到的分布一个高斯每个输入一个高斯每个前文一个类别分布每个 (xt, t) 一个以 D 为中心的高斯

只有没有输入时，模型参数和分布参数才是同一个东西。一旦有输入，两者就分开了。拿最简单的线性回归 μ(x) = 2x + 1 来说：权重是 2 和 1，训练好以后就固定了；μ 却随输入变化，x = 3 时是 7，x = 5 时是 11。

大模型那一列：网络先为每个前文算出 logits，也就是给词表里每个 token 打一个分数，相当于没归一化的对数概率；softmax 再把这组分数变成一个类别分布。

训练好的模型（权重固定）是族里的一个成员。有输入时，这一个成员是一个条件分布：给它任何输入，它都能当场算出对应的那个分布。推理时调温度、top-p，改的只是从这个分布里采样的方式，成员本身没变。

权重是"算分布参数的规则"；μ 和 logits 是"按规则针对某个输入算出来的结果"。

6训练：最大似然与最大后验

训练是在分布族里挑出一个成员，让训练数据在它下面出现的概率最大，这叫最大似然；再加上正则项，相当于乘上一个先验，叫最大后验。两种做法都只交出一组权重。

训练时，不知道的是权重 θ，看到的是训练数据。于是第 3 节的四个角色换了一批东西来当：

  • 似然：用权重 θ 给每条训练数据的答案打分，再全部乘起来（这里假设数据之间独立同分布）。有输入时叫条件似然：L(θ) = pθ(y₁ | x₁) × … × pθ(yN | xN)，只给输出 y 打分，输入 x 只当条件。没有输入时：L(θ) = pθ(x₁) × … × pθ(xN)。
  • 最大似然：找让 L(θ) 最大的 θ。连乘取对数会变成相加，再取负号，就是平时最小化的 loss。
  • 先验：训练前对权重的预设，对应正则项。L2 正则等价于"权重服从中心在 0 的高斯分布"。
  • 后验与最大后验：−log 后验 = loss + 正则项 + 常数。最小化"loss + 正则项"，就是在找后验最高的那组权重。完整的后验分布不计算，参数太多，列不出来。
  • 证据：和 θ 无关，是常数，训练时直接丢掉。

关于先验，有三点要说清：

  • "不加正则 = 没有偏好"不对。权重是任意实数，在整个实数轴上"均匀"的分布凑不成 100%，严格说只能叫平坦先验；而且架构、初始化和优化器本身就让模型更容易学到某些函数，这些都是隐式的偏好。
  • 权重不直接等于输出分布，所以"权重越小越合理"并不能直接翻译成"模型偏好什么样的输出"。真正决定模型偏好什么输出的，更多是架构。
  • 大模型常用的 AdamW weight decay 和 L2 正则不严格等价，研究也表明它在大模型里主要改善的是优化过程，而不是充当先验。

为什么 loss 是交叉熵或 MSE

loss 就是负对数似然，所以输出用什么分布，就决定了 loss 长什么样：

  • 输出是类别分布（分类、大模型）：−log pθ(y | x) 就是交叉熵。
  • 输出是高斯分布（回归、扩散去噪）：假设 y = μ(x) + 高斯误差，标准差 σ 固定，那么

−log N(y; μ(x), σ²) = (y − μ(x))² / (2σ²) + 常数

平方来自高斯密度的指数部分，取对数后正好剩下误差的平方。所以最小化 MSE，就等于在"误差是高斯"的假设下做最大似然。换成拉普拉斯误差，得到的就是 L1 loss。

这是等价关系，不是使用前提：误差不是高斯时，MSE 照样能用，它学到的仍然是条件均值（第 4 节）。

选了什么样的误差分布，就得到什么样的 loss。

两层贝叶斯，千万别混

扩散模型里同时有两个"未知量"，各有自己的一套先验、似然、后验、证据：

训练层：找权重去噪层：猜原图
未知的网络权重 θ干净数据 x₀
看到的一批训练配对一张加噪图 xt
先验对权重的预设：正则项，以及架构带来的隐式偏好数据分布：本例是 ±1 各一半
似然这组权重给训练答案打的分，取负对数就是 MSE loss加噪规则 p(xt | x₀)，我们自己定的
后验不计算，只取一组权重p(x₀ | xt)，网络输出的是它的均值
证据不计算加噪图本身的分布 p(xt)

下篇说"网络学到的是后验均值"，指的是右边一列；训练这个网络用的最大似然，在左边一列。

7交叉熵与 KL 散度

交叉熵就是训练集上的平均负对数似然，两者是同一个式子。KL 散度里，写在前面的分布决定"在谁的样本上检查"。

把训练集本身看成一个分布，每条样本占 1/N，叫经验分布。它和模型分布之间的交叉熵，展开后就是"对每条训练样本求 −log pθ(样本)，再取平均"，也就是平均负对数似然。这不是巧合，而是同一个量：信息论把它叫"用模型给数据编码的平均长度"，统计学把它叫负对数似然。

loss 降不到 0 的那部分，是数据本身的不确定性，叫熵。同一个输入可能对应好几个答案时，谁也不可能每次都猜对。

KL 散度衡量两个分布差多少：

KL(P ‖ Q) = 对所有 x 求和：P(x) · log( P(x) / Q(x) ) = 交叉熵 − 熵

前面乘的 P(x) 表示"按 P 的样本取平均"。所以写在前面的分布提供样本，后面的分布接受检查，两者不能随便交换：

前向 KL：KL(数据 ‖ 模型)反向 KL：KL(模型 ‖ 目标)
在谁的样本上检查数据的样本模型自己生成的样本
罚得最重的情况数据里有的，模型几乎给了 0模型生成的，目标几乎给了 0
倾向宁滥勿缺：要覆盖数据的所有部分，覆盖不了时会把概率摊到中间宁缺毋滥：只待在目标认可的地方，可能丢掉一部分
对应的训练最大似然、SFT带 KL 约束的强化学习、on-policy 蒸馏

前向 KL 等于交叉熵减去数据的熵，而数据的熵和模型无关，所以最小化前向 KL = 最小化交叉熵 = 最大似然。表里"倾向"那一行在模型能力不足时最明显，对表达能力很强的模型只是一种倾向。

两点补充：

  • 最大似然的定义里只有"模型 + 数据"，不需要"真实分布"。说它在逼近"真实分布"时，指的是数据生成分布：谁产生了训练数据，它就逼近谁，连数据的偏差一起学。
  • 强化学习不是最大似然：它没有可以模仿的样本，只有打分；样本是模型自己采的，会随权重变化；权重（优势值）还可以是负的。

8扩散的训练在学什么

训练时我们自己给数据加噪，再让网络用 MSE 从 xt 猜 x₀。按第 4 节，网络学到的是后验均值 D(x, t) = E[x₀ | xt = x]。

每条训练样本是这样造出来的：随机抽一个 x₀、一个噪声 ε、一个 t，按第 2 节的规则算出 xt。网络的输入是 (xt, t)，要猜的目标是 x₀，loss 是 MSE。

按第 6 节，这是条件高斯的最大似然；按第 4 节，同一个 (xt, t) 可能来自不同的 x₀，所以网络学到的是它们的均值。实际训练里常让网络预测噪声 ε 或速度 v，三者可以互相换算，学到的都是同一个后验的均值。

本例的后验均值能精确写出来，就是第 4 节的 D(x, t) = tanh((1 − t)·x / t²)。真实的网络学到的是它的近似。

一步和多步用的是同一个网络、同一个训练。区别只在采样时怎么用它。推理时权重不再变化；每一步"重新算后验"，是因为输入的 xt 换了，不是网络又学了什么。

一步
纯噪声 x₁→网络→E[x₀ | x₁]所有训练数据的平均
多步
纯噪声 x₁→网络→走一小步→网络→走一小步→ … →E[x₀ | x末]一个具体的样本

所以要回答的问题是：同一个"条件均值"，为什么只用一次得到平均，接起来用却得到样本？

9采样：常微分方程与欧拉法

采样就是沿着速度场从噪声走到数据。欧拉法每一步按当前速度走一小段直线；在本例里，这等于"朝当前的猜测 D 走一部分路"。

常微分方程（ODE）说的是：告诉你每个位置、每个时刻的速度，求出整条轨迹。

速度从哪来？训练时，xt = (1 − t)·x₀ + t·ε 随 t 变化的速度是 ε − x₀。采样时既不知道 ε 也不知道 x₀，只能用它们在当前位置的条件均值，这就是速度场：

v(x, t) = E[ε − x₀ | xt = x] = (x − D(x, t)) / t

推导：由加噪规则得 ε = (x − (1 − t)·x₀) / t，代入 ε − x₀ 再取条件均值，x₀ 的位置换成 D 即可。

这个方程一般没有现成的解，只能一步步近似地算。最简单的办法叫欧拉法：假设速度在一小段时间里不变，沿直线走一步，到了新位置再重新算速度。从时刻 t 走到更小的时刻 s：

xs = xt + (s − t) · v = (s/t) · xt + (1 − s/t) · D(xt, t)

右边这个形式有一个很直观的几何意义：把当前点 (t, xt) 和"终点处的猜测" (0, D) 连成一条直线，欧拉法就是沿这条直线走到时刻 s。最后一步走到 s = 0 时，输出正好等于 D，也就是最后一次的猜测。

名字别混：这里是"欧拉法"，一种解常微分方程的数值方法。"欧拉方程"通常指流体力学或变分法里的另一组方程，和这里无关。

不管走几步，最后的输出都是一个条件均值。区别只在于做最后一次猜测时，条件里有多少信息。

10一步：只能得到平均

从纯噪声一步走到底，输出等于 E[x₀ | x₁]。而 x₁ 和 x₀ 独立，看了等于没看，后验就是先验，所以输出就是全体训练数据的平均。

三步推出来：

  1. 只走一步，就是从 t = 1 直接走到 s = 0。按上一节的公式，输出 = D(x₁, 1) = E[x₀ | x₁]。
  2. t = 1 时 x₁ = ε，和 x₀ 独立（第 2 节）。独立的意思就是"知道 x₁ 对 x₀ 没有任何信息"，所以后验 p(x₀ | x₁) 就等于先验 p(x₀)。
  3. 于是输出 = 先验的均值 = E[x₀] = 0（第 1 节）。

这个结论和网络有多强无关，也和数据长什么样无关。换成真实图片：一步生成的结果，就是训练集里所有图片逐像素的平均，一张糊图。

步数输出的平均 |x₀|落在 ±1 附近落在两峰之间看到了什么

和开头的图用同一套计算。2 步时有一个干净的结论：第一步从 t = 1 走到 0.5，猜测是 0，所以 x0.5 = ε / 2；第二步交出 E[x₀ | x0.5] = tanh(ε)，结果摊在 −1 和 1 之间，是"半糊"的。

11多步：为什么最后是样本

多步时，每一次猜测面对的后验都比上一次更窄。到最后一步，后验几乎只剩一个峰，它的均值就是一个具体的答案。

先在真实的图片上看一遍，再分三层解释。第一层看后验怎么变窄；第二层说明"每一步只用均值"为什么够用，适用于随机采样器；第三层说明确定性的 ODE 采样器为什么能得到整个数据分布。

先在图片上看一遍

把两点例子换成第 12 节那 12 张猫的简笔画（缩成 64 × 48 像素），加噪和去噪都按真实的方式逐像素进行。去噪用的不是训练出来的网络，而是这 12 张图上精确的后验均值：每一步先算"眼前这张噪声图来自每一只猫的可能"，再按这个可能把 12 只猫加权平均。

因为去噪器是精确的，多步最后会还原成 12 张训练图中的某一张，这就是第 12 节说的"记忆"。真实网络学到的是不完美的版本，能生成新图，但一步和多步的区别是一样的。图里也可以把去噪器换成"局部"的，看它怎样拼出训练集里没有的图（第 12 节会解释）。

上排是每一步开始时的位置，下排是这一步的猜测：从一张糊图，慢慢变成一只具体的猫。

这张图里能看到下面三层要解释的三件事：

  • 一步就是平均：t = 1 时后验等于先验，12 只猫各占 1/12，猜测就是平均图，换噪声也不变（第 10 节）。
  • 猜测越来越确定：下排的百分比，也就是后验里占比最大的那只猫的权重，从 8% 一路涨到接近 100%。噪声在变小，后验在收缩（第一层）。
  • 步子太大会丢掉噪声里的信息：只走 2 步时，第一步就把位置拉到"一半噪声 + 一半平均图"，噪声带来的信息被冲掉了大半，第二步再猜，结果容易集中到少数几只"最普通"的猫上。真实网络在步数太少时，通常表现为模糊和细节缺失；这里的去噪器是精确的，所以表现成多样性丢失。步数足够多以后，同一个噪声的结果基本不再变化，已经接近 ODE 的精确解（第二、三层）。

第一层：后验越来越窄，信息来自噪声变小

选一个起点噪声，拖动进度条。左图是这个点此刻的位置 xt，右图是此刻的猜测 D(x, t) 作为 x 的函数，也就是第 4 节那条 tanh 曲线在当前 t 下的样子。下方的色条是此刻的后验。

盯住右图：曲线从一条水平线，慢慢立成一级台阶。

以 ε = 0.8 为例，xt 一直在 0.6 到 0.9 之间晃，变的是右边那条曲线。t = 1 时它是水平线：不管 x 是多少，猜测都是 0，因为后验就是先验。t 越小曲线越陡，最后变成台阶：x > 0 就猜 +1，x < 0 就猜 −1。

同一个位置 x ≈ 0.61：t = 0.7 时噪声还大，看不出它来自哪个峰，后验接近各半，猜 0.358；到 t = 0.5 时噪声小了，同一个位置已经能说明"多半来自 +1"，后验约 92% 对 8%，猜 0.841。

一步时，最后一次猜测的条件是 x₁，信息为零；多步时，最后一次猜测的条件是 x末，噪声已经很小，后验几乎只剩一个峰。

信息不是靠"走得远"得来的，是靠噪声变小。同一个位置，噪声越小，说明的事越多。

第二层：步子小时，一步之内的后验接近单峰高斯

随机采样器（DDPM 这一类）每一步要做的，是从"往回退一小步"的后验 p(xs | xt) 里随机抽出下一个位置。它的做法是：用网络给的均值，配一个事先定好的方差，画一个高斯，从里面抽。这个做法什么时候是对的？

按贝叶斯公式，p(xs | xt) 正比于两项相乘：这一小步加噪的似然，是一个很窄的高斯；上一时刻的分布 ps，它在噪声的尺度上是平滑的。很窄的范围里，平滑的曲线近似一条直线，两者相乘还是高斯。所以步子小时，一步之内的后验近似是一个方差已知的高斯，而方差已知的高斯，均值就是它的全部信息。学到均值，再按已知方差抽样，就精确地完成了这一步。

均值丢不丢信息，不看均值本身，看被平均的那个分布：单峰而且窄，就不丢。

这个机制成立的条件是：这一步加的噪声，要远小于已经有的噪声，也就是相对步长 (σt² − σs²) / σs² 远小于 1。步子太大，一步之内的后验又裂成两个峰，"均值 + 固定方差"的高斯就落在两峰之间，抽出来的点是糊的。

所以切分时间步要看相对步长。按绝对值看，噪声越小，步子要越小。

一个常见的误解：说"调度器在高噪声段把步子排得更密"，作为一般规律不对。按上面的条件，低噪声端的绝对步长要更小，EDM 的调度就是低噪声端更密。SD3 这类高分辨率模型会把步子往高噪声端挪，那是为了应对"分辨率越高，信号越不容易被噪声盖住"，是另一个考虑。

第三层：平均速度搬运的是整个分布

训练时，每一对 (ε, x₀) 之间连一条直线；网络学的是"经过某一点的所有直线，速度的平均"。采样时，点沿着这个平均速度走，并不沿着任何一条原始的直线。

可以想象人群穿过广场：每个人都有自己计划的直线路线，路线彼此交叉；但人群在每个位置的流速，是经过那里所有人速度的平均。跟着人流走，每个人都会走到某个出口，各个出口的人数比例也是对的，只是不一定是他原本计划的那个出口。

数学上，这由连续性方程保证：某处的概率变化 = 流进来的 − 流出去的，而流量 = 密度 × 平均速度。所以按平均速度推着走，每个时刻点的分布正好是 pt，最后正好是数据分布。这是 flow matching 论文里的定理。

平均速度不是某一个人的速度，是人流的速度。人流的速度，搬运的是整群人。

常微分方程的解不会交叉。x = 0 这条线始终不动，因为那里的猜测是 0、速度是 0。所以 ε > 0 的点全部走到 +1，ε < 0 的点全部走到 −1：从噪声到数据的对应关系是 Φ(ε) = sign(ε)，即正数对应 +1、负数对应 −1。

但在训练配对里，ε = 0.8 有一半时候配的是 −1，因为 ε 和 x₀ 是独立配对的。直接拿这些配对做回归，只能学到 0。"这个 ε 该去哪"这个确定的对应关系，训练数据里根本没有，是沿平均速度一步步走出来的。

这也说明了一步蒸馏在做什么：reflow 和蒸馏先用多步 ODE 为每个 ε 算出确定的终点，再拿 (ε, Φ(ε)) 去回归。目标确定了，回归学到的就不再是均值。难点在于这个对应关系在两峰交界处是跳变的，一步网络要拟合这种陡峭的变化。这一点是推断，不是论文结论。

训练数据里只有"ε 和 x₀ 随机配对"；"这个 ε 该去哪"是采样时才算出来的。

更深一层：信息一直都在，只是一步取不出来

把猜测看成 x 的函数 D(·, t)，就是第一层右图那条曲线。Tweedie 公式说，后验均值可以由 score（log 密度上升最快的方向）算出来：

E[x₀ | xt] = ( xt + σt² · ∇log pt(xt) ) / αt，本例中 αt = 1 − t，σt = t

反过来，知道每一处的 D，就知道每一处的 score，也就确定了整个 pt。所以"学去噪"和"学 score"是同一件事，而且任何 t < 1 时的这条曲线，理论上都含有数据分布的全部信息：pt 是数据分布被高斯"模糊"后的结果，而高斯模糊是可以逆转的。

一步生成的问题在于只用了 t = 1 这一处，那里曲线是一条水平线，信息为零。t 接近 1 时信息还在，但只藏在曲线极其微小的起伏里。想直接把它还原，相当于把一张被高度模糊的图一次反模糊回来，细节越精细，需要放大的倍数越大，任何有限精度的网络都扛不住。多步采样，等于把这一次困难的大反模糊，拆成很多次容易的小去噪。

12条件均值不就是目标吗

学条件均值是训练目标，没问题；但生成要的是"从分布里抽一个样本"，交出条件均值就是交出一张糊图。

训练目标

在每个噪声程度、每个位置上，学 E[x₀ | xt, 条件]。它是一个中间量，和 score 等价。

学条件均值：对，这正是要学的。

生成目标

从 p(x | "波斯猫") 里抽一张图。每次不同，每张都像一张真实照片。

直接交出条件均值：不对，那是一张糊图。

E[x | "一只波斯猫"] 正好就是一步生成的输出：训练集里所有波斯猫照片逐像素求平均。下面这台平均器用简笔画代替照片，平均是逐像素精确计算的。

道理和两点例子一样：真实图片分布在一个弯曲的低维"曲面"上，曲面上两个点的平均落在曲面外面，就像 +1 和 −1 的平均 0 不是任何一个数据点。朝左的猫和朝右的猫平均，得到的是两只半透明的猫叠在一起，不是一只朝正面的猫。

"平均脸"看起来像脸，正好是个反例：做之前已经按五官位置把照片对齐了。对齐等于人工去掉了姿态和位置的变化，让剩下的分布接近单峰，均值才清楚。多步采样在自动做这件事：到后期，xt 已经定下了姿态、构图和背景，后验里剩下的只有细微差别。

另外，人说的"典型的波斯猫"不是像素平均，而是一个处在高概率区域的具体样本。均值也没有多样性：同一个提示词永远输出同一张图。

像素的平均，不是语义的平均。

连"复现训练图"也不是目标

训练集只有有限的 N 张图。如果网络精确学到了这个训练集上的条件均值，那么 pt 就是 N 个高斯叠在一起，用精确的采样器跑出来的，只会是 N 张训练图之一，也就是纯粹的记忆。开头那个两点例子正是这样：两张"训练图" ±1，采出来的永远只有 ±1。

学得"太准"，反而只会背答案。

能生成新的波斯猫，靠的恰恰是网络没有完美拟合经验最优解。数据少时，扩散模型确实会复制训练图（Somepalli 等，CVPR 2023）。Kadkhodaie 等（ICLR 2024）发现，训练集足够大时，用不相交的两半数据分别训练出的两个模型，会生成几乎相同的图：它们学到的是数据背后的分布，而不是各自记住的样本。

新图从哪来：局部拼贴与概念组合

真实网络能生成训练集里没有的图，包括把不同样本的部件、属性拼到一起。Kamb 和 Ganguli（ICML 2025）找到了两个关键原因：卷积网络每个位置只看一小块邻域（局部性），而且同一套权重用在每个位置（平移等变）。这让每一小块区域只参考训练图里"长得像的小块"，这些小块可以来自不同的训练图。结果是一张局部处处合理的拼贴图，可能的组合多到指数级。按这个原理写出的解析模型，能以 r² ≈ 0.95 的精度预测训练好的卷积扩散模型的输出；注意力层则负责让拼贴在语义上整体一致。

第 11 节的图片演示里可以把去噪器切换成"局部"的：每个位置只按周围 7×7 或 13×13 的小块计算后验。这时输出不再是任何一张训练图，而是一张新图；但只有局部信息时，拼出来的往往整体不像一只猫。局部性负责"拼"，要拼成一只合理的新猫，还需要全局的信息。

在概念层面，Okawa 等（NeurIPS 2023）发现条件扩散模型能生成训练里没出现过的概念组合，比如没见过的"形状 × 颜色"搭配。但这种能力由各个单项能力相乘而来，越罕见的组合需要越多训练；属性张冠李戴、数量不对，也都是常见的失败。

完美拟合只会背；不完美、但带着合适偏置的拟合，才会创造。更多研究见扩散模型泛化研究整理。

用什么得到什么

精确的经验条件均值 + 精确的多步采样训练图原样复现（上图 h = 0）
只看局部的去噪器 + 多步采样训练集里没有的新图：局部合理，整体不一定合理（第 11 节可切换）

13为什么 LLM 一次定一个 token，扩散却要反复重算

区别在于每一步要同时决定多少东西、用什么分布来表示：LLM 每步只定 1 个离散 token，类别分布能精确表示"可能是 A，也可能是 B"，抽一个就定下来；扩散每步要同时定整张图几十万个连续数值，只能用均值来表示，只有步子小时才准。

LLM（自回归）扩散
怎么拆按位置：一次定一个 token按噪声程度：每次把整张图变清楚一点
每一步要表示的分布下一个 token 是谁：离散，几万种可能下一步整张图在哪：连续，几十万维
用什么表示类别分布，能表示任意多个峰均值，相当于一个单峰高斯
能不能直接抽样能，精确地抽只有步子小时，均值才够用
前面的结果改不改不改，抽出的 token 成为后面的前文每一步都改整张图

两者推理时权重都固定不变，变的是每一步的输入。LLM 每生成一个 token，前文就多一个 token，同一套权重据此算出新的下一个 token 分布，这就是链式法则；扩散每走一步，xt 就换成一个噪声更小的新位置，同一套权重据此算出新的后验均值。区别只在于：LLM 每次添上一块定下来的内容，扩散每次把整张图一起改清楚。

一步同时决定很多维，会丢掉维度之间的关联。连续的情况只能给均值：朝左和朝右的猫平均成一张糊图。离散的情况只能让每个位置各自独立地抽，也就是假设它们条件独立。非自回归翻译有个经典例子：英文"Thank you"可以译成德文"Danke schön"，也可以译成"Vielen Dank"；各位置独立地抽，就可能拼出"Danke Dank"（Gu 等，2018）。LLM 每步只定一维，后面的维度以它为条件，关联一点不丢。

扩散的多步和 LLM 的逐 token，解决的是同一个问题：不要在一步里替很多相互关联的维度同时做决定。

这也不是"文本和图像"的区别：

  • 图像可以像 LLM 一样生成：先切成离散的 token，再一个一个预测，每步是一个类别分布，完全不用去噪，比如 DALL·E 1、Parti、LlamaGen。
  • 文本可以像扩散一样生成：LLaDA 这类掩码扩散语言模型从"全部遮住"开始，每步同时预测所有被遮住的位置，再把没把握的重新遮上，要走很多步；一次揭开太多，就会出现"Danke Dank"式的错误。
  • 连续的 token 即使自回归，也不能只给均值：MAR（Li 等，2024）给每个连续 token 配一个小扩散模型来表示它的分布，否则还是糊。

所以，"是不是每个 token 都是一次去噪"：不完全是，但有联系。自回归可以看成一种特殊的掩码扩散：每步按固定顺序只揭开一个位置，并且精确地抽样。"是不是闭合解的问题"：不是。LLM 每一步同样没有闭合解；关键是这一步的分布能不能被选用的分布形式精确表示，并且能直接从中抽样。

14一句话

每一步学条件均值，没有问题；只用一次条件均值，才是问题。多步采样让每一次猜测面对的后验都足够窄，均值不再抹掉信息，最后一次的均值就是一个具体的样本。

训练

在分布族里做最大似然（MSE），网络学到后验均值 E[x₀ | xt]。

一步

x₁ 与 x₀ 独立，后验 = 先验，输出 = 全体数据的平均。

多步

噪声逐步变小，后验逐步变窄，最后的均值就是一个样本。

容易混的一点：推理不是在"取后验最大值"

训练推理（生成）
未知的是权重 θ要生成的图或文本
目标最大似然，加正则相当于最大后验；只留下一组权重从分布里抽一个样本，不是挑最可能的那一个
扩散每一步用的—后验的均值（第 4 节），不是后验的最大值
LLM 每一步用的—从下一个 token 的分布里抽样；只有贪心解码才是每步取最大

一个后验可以给出三样不同的东西：均值、最大值（最可能的那个值）、一个随机样本。在两点例子里，t = 0.5、xt ≈ 0.61 时后验是 +1 占 92%、−1 占 8%：均值是 0.84，最大值是 +1，样本则 92% 的时候是 +1、8% 的时候是 −1。扩散每一步拿均值往前走；走完多步后，输出落在 +1 或 −1 上，而且比例正确，所以整体上是在"抽样本"。

为什么生成时不取后验或分布的最大值，下面用两个演示说明。

为什么不取最大值

原因一：取最大值会丢掉多样性。模型分布说"+1 占 60%、−1 占 40%"，意思是 10 次里应该有 4 次是 −1。如果每次都取最可能的那个，10 次全是 +1，那 40% 永远不会出现。LLM 的贪心解码就是这样：同一个提示词，永远得到同一句话。

Holtzman 等（ICLR 2020）还发现，在长文本上一味追求最高概率（比如 beam search），得到的往往是平淡、重复、甚至原地打转的文字；人写的文字并不是概率最高的那一句。

分布说"有 40% 的可能"，取最大值等于把这 40% 当成 0。

原因二：在高维空间里，最可能的那个点不像样本。这一点反直觉，关键是分清两件事："某一个点的密度"，和"落在某一片区域里的概率"。第 1 节说过，概率是密度曲线下的面积，粗略地说就是"密度 × 这片区域有多大"。

以标准高斯 N(0, I) 为例。它在原点的密度最高，离原点越远，密度越低。但离原点越远，同样厚度的"一圈"所包含的空间就越大；在 d 维里，这个空间大约按距离的 d − 1 次方增长。密度在变小，空间增长得更快，两者一乘，概率就集中在离原点约 √d 的一圈薄壳上，这叫典型集合。维度越高，这一圈离原点越远，原点附近几乎没有概率。

密度最高的地方，不等于样本最多的地方。维度越高，两者离得越远。

放到图像上：9216 维的 N(0, I) 里密度最高的点是全 0，显示出来是一张平灰图；它的密度大约是一张典型噪声图的 102001 倍。可你从这个分布里抽一辈子，也抽不到它，甚至抽不到离它近一点的图：抽出来的每一张离原点都在 96 左右，落在离原点 1 以内的概率大约是 10−16270。

真实的生成模型也有同样的现象。Nalisnick 等（ICLR 2019）发现，几种能算出似然的图像生成模型，给出最高似然的是常数图这类最简单的图，甚至会给没见过的、更"平淡"的数据集打出比训练集更高的似然。所以"最可能的那张图"，不是我们想要生成的图。

·术语表

按在正文里出现的大致顺序排列。每条说明它是什么，以及在本页里指什么。

分布与随机变量

随机变量
结果还没确定的量。本页里：随手抽一条训练数据 x₀，以及噪声 ε。
概率分布
说明随机变量的每种可能各占多少，全部加起来是 100%；连续变量是"曲线下总面积为 1"。
类别分布
从有限个类别里选一个，每个类别有自己的概率。大模型每个位置输出的就是它。中文常把它叫"多项分布"，严格说多项分布是"抽 n 次、各类别被抽中几次"，类别分布是 n = 1 的情况。
离散与连续
离散：只能从有限个选项里挑一个，比如词表里的某个 token，两个选项"之间"没有合法的值。连续：可以取一个范围内的任意实数，比如像素值或潜变量 0.3127……。连续时，两个值的平均本身仍是一个合法的点，所以 MSE 才能输出"平均图"；离散时，两个 token 的平均不是 token，只能输出概率再从中挑一个。例：图片里一个像素存成整数 200，送进扩散模型前先换算成实数 200 / 127.5 − 1 ≈ 0.5686，加噪、去噪过程中它可以是 0.1280、0.5521 这类任意实数，只在最后保存时才四舍五入回整数。
概率密度
连续变量用的"单位长度上的概率"。落在某个区间里的概率，等于密度曲线在这个区间下的面积；恰好等于某一个值的概率是 0。密度本身可以大于 1。
期望（均值）
每个可能的值乘以它的概率，再加起来。x₀ 的期望是 0。
方差与标准差
方差：各个值离均值的距离，取平方后按概率平均。标准差是方差的平方根，单位和原数据相同，表示"一般偏离均值多远"。
高斯分布（正态分布）
钟形曲线，记作 N(μ, σ²)：μ 是中心，σ 是标准差，括号里第二个位置写的是方差。只有一个峰。噪声 ε 服从 N(0, 1)。
典型集合
高维分布里几乎全部概率所在的那片区域。对 d 维标准高斯，它是离原点约 √d 的一圈薄壳；密度最高的原点反而不在里面，随手抽的样本几乎都落在这圈薄壳上。
单峰与多峰
分布有几个"最可能的区域"。多峰分布的均值可能落在峰与峰之间概率很低的地方，比如 ±1 的均值 0。

多个变量

联合分布
几个量同时取某一组值的可能，比如 p(x₀, xt)。
条件概率与条件分布
已知某个量的取值时，另一个量的分布，写作 p(a | b)：竖线右边是已知的，左边是要问的。做法是只看满足条件的那部分情况，再重新凑成 100%。
边缘分布
不管其他量取什么，只看一个量的分布，做法是把各种情况按概率加起来。贝叶斯公式里的"证据"就是它。
独立
知道一个量，对另一个量没有任何信息，即 p(a | b) = p(a)。本页：ε 和 x₀ 独立；t = 1 时 xt 和 x₀ 独立。
独立同分布
数据之间互相独立，而且来自同一个分布。似然能写成"每条数据的概率连乘"，依赖的就是这个假设；重复或同源的数据多了，这个假设就不成立。
条件独立
给定某个条件后，几个量之间互不提供信息：p(a, b | c) = p(a | c) · p(b | c)。一步同时生成很多 token、让每个位置各自抽样，就是在假设它们条件独立，会丢掉它们之间的关联。
链式法则
p(a, b) = p(a) · p(b | a)，量多时一路乘下去。它是精确成立的，不需要独立假设。大模型给整段文本算概率，就是一个 token 一个 token 乘出来的。

贝叶斯公式

贝叶斯公式
p(未知 | 看到的) = p(看到的 | 未知) × p(未知) ÷ p(看到的)，即后验 = 似然 × 先验 ÷ 证据。来历：两件事同时发生的概率按两种顺序算，结果必然相等。
先验
看到数据之前，对未知量的判断。去噪层里是数据分布（±1 各半）；训练层里是对权重的预设，对应正则项。
似然
把已经看到的数据固定下来，把 p(数据 | 候选) 当作候选的函数，给每个候选打分。它不是候选的概率分布，几个分数加起来一般不是 1，只有相对大小有意义。
后验
看到数据之后，对未知量的判断，等于似然乘先验再归一化。去噪层里是 p(x₀ | xt)。
证据（边缘似然）
不区分是哪个候选，看到这份数据本身的概率，是贝叶斯公式的分母。去噪层里是 p(xt)；训练层里和权重无关，训练时直接丢掉。
条件期望 / 后验均值
已知条件下的期望。E[x₀ | xt] 就是把 x₀ 的每个可能取值按后验概率加权平均。用 MSE 训练的网络，学到的就是它。

模型与训练

分布族
形式相同、只差几个参数的一组分布。架构决定族，权重从族里选出一个成员。
模型参数与分布参数
模型参数是训练时调的数，即权重；分布参数是决定某一个具体分布的数，比如 μ、logits。有输入时，分布参数由权重和输入一起算出来，两者不是同一个东西。
条件似然
有输入时的似然：pθ(y₁ | x₁) × … × pθ(yN | xN)。只给输出打分，输入只当条件。SFT 不计 prompt 的 loss，就是这个意思。
最大似然估计（MLE）
在分布族里找让训练数据似然最大的参数。取负对数后，就是最小化交叉熵、MSE 这类 loss。
最大后验估计（MAP）
找让后验最大的参数，等于最小化"loss + 正则项"。只取后验的最高点，不保留整个后验分布。
自回归
按顺序一次生成一个元素，每个元素以前面已经生成的全部内容为条件。按链式法则，整体概率 = 每一步条件概率的连乘。LLM 就是这样生成 token 的。
众数与贪心解码
众数是一个分布里概率（或密度）最高的那个值，也就是"最可能的那一个"。贪心解码是生成时每一步都取当前分布的众数。它给出的是最可能的结果，不是一个样本，所以没有多样性。
MSE（均方误差）
误差平方的平均。它等于"误差服从方差固定的高斯分布"时的负对数似然（差一个常数和系数）；它的最优解是条件均值。
softmax 与 logits
logits 是网络给每个类别打的原始分数，相当于没归一化的对数概率，只有差值有意义。softmax 先对每个分数取指数，再除以总和，把它们变成类别分布。两个 logit 差 1，概率相差约 2.7 倍。

交叉熵与 KL

经验分布
把训练集本身当成一个分布，每条样本占 1/N。数据越多，它越接近数据生成分布，这是大数定律的结论。
数据生成分布
产生训练数据的那个分布：可以是现实中的语料、筛选和配比后的数据集，也可以是教师模型。最大似然逼近的就是它，连它的偏差一起。
交叉熵
H(P, Q)：按 P 的样本取平均的 −log Q。P 取经验分布时，它就是平均负对数似然。信息论里把它解释为"用 Q 给 P 的数据编码，平均需要的长度"。
熵
一个分布自身的不确定性，H(P) = 按 P 取平均的 −log P。它是交叉熵的下限，也就是 loss 降不下去的那部分。
KL 散度
KL(P ‖ Q) = 对所有 x 求和 P(x)·log(P(x)/Q(x)) = 交叉熵 − 熵。永远不小于 0，只有两个分布完全相同时为 0，而且不对称。"‖"只是分隔，前面的分布提供样本，后面的接受检查。前向 KL(数据 ‖ 模型) 对应最大似然；反向 KL(模型 ‖ 目标) 对应带 KL 约束的强化学习。

采样的数学

常微分方程（ODE）
给出"每个位置、每个时刻该怎么变"，求整条轨迹。本页是 dx/dt = v(x, t)。
欧拉法
求常微分方程近似解的最简单办法：假设速度在一小段时间里不变，沿直线走一步，再重新算速度。步子越小越准。注意它不是"欧拉方程"，后者通常指流体力学或变分法里的另一组方程。
速度场
每个位置、每个时刻的速度。本页是 v(x, t) = (x − D(x, t)) / t，等于训练时所有经过这一点的直线速度的平均。
连续性方程
描述"一群点按速度场移动时，它们的分布怎么跟着变"：某处概率的变化 = 流进来的 − 流出去的，流量 = 密度 × 速度。Flow matching 用它证明：按平均速度走，每个时刻的分布正好是 pt。
score
log 密度的梯度 ∇log p(x)，也就是"往哪个方向走，密度上升得最快"。梯度是一个函数在某点增长最快的方向和速度。
Tweedie 公式
对 xt = αt·x₀ + σt·ε，有 E[x₀ | xt] = (xt + σt²·∇log pt(xt)) / αt。后验均值可以由 score 算出来，所以"学去噪"和"学 score"是同一件事。
总变差
衡量两个分布有多大部分不重合：0 表示完全相同，100% 表示完全不重叠。
核平滑
把每个数据点抹成一个小钟形再叠加，得到一条平滑的分布；宽度 h 越大越平滑。本页用它示意"网络没有完美拟合训练集"。
记忆与泛化
只会复现训练样本，叫记忆；能生成训练集里没有、但同样合理的样本，叫泛化。
